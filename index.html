  1. Open WhatsApp → Settings → Linked devices.

Before you link: the bot becomes a linked device on your WhatsApp, so it can see the messages you receive and send messages as you. Use it only if you trust the owner. WhatsApp does not allow unofficial bots, so the number can be banned. You can remove it any time: WhatsApp → Linked devices → BIN_SAID → Log out. You don't need to link anything to use the Chat tab.
